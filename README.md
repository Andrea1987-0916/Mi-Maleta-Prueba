# Mi Maleta — André & Yosef

## Contenido
- `index.html`: aplicación web en un solo archivo, con ilustraciones SVG integradas.
- `manifest.webmanifest`: configuración para instalarla en la pantalla de inicio.
- `apple-touch-icon.png` e `icon-512.png`: iconos de la aplicación.
- `cover.jpg`: imagen de portada.

## Publicación
Sube el contenido de esta carpeta a la raíz del repositorio de GitHub Pages, reemplazando los archivos solo cuando hayas guardado una copia de la versión anterior. No subas la carpeta contenedora como una subcarpeta.

## Datos
Los datos se guardan en el almacenamiento local del navegador. No se sincronizan automáticamente entre dispositivos. Usa la función de copia de seguridad dentro de Ajustes y conserva una copia fuera del teléfono.

## Estado de validación
La versión publicada se probó en Safari para crear un viaje y observar que la lista inicial se genera y que marcar un artículo actualiza el progreso. Esta candidata integra ilustraciones SVG por categoría y por tipo de artículo, pero requiere una comprobación visual final en Safari y una prueba explícita de persistencia tras recargar antes de considerarse entrega definitiva.
